# design system

Tokens and components for every design after v1. v1 (the current site) keeps
its own CSS and is locked by `tests/design`.

## use

```tsx
import "@/design-system/ds.css"; // once, in a design's root
import { AppShell, PageHeader, StatGrid, Link } from "@/design-system";
```

Everything renders inside an element with class `ds`. `AppShell` provides it;
otherwise wrap with `<div className="ds">`. Theme follows the site's
`theme-dark` class, or can be forced with `data-theme="light|dark"`. The accent
is set with `data-accent="neutral|blue|amber|green"`.

## files

| file | what |
|---|---|
| `tokens.ts` | source of truth: colors (light + dark, per accent), type, space, radius, shadow, motion, z |
| `generate.ts` → `tokens.css` | css variables (`--ds-*`), generated by `npm run tokens`; a unit test fails if stale |
| `ds.css` | component styles; only tokens, only `.ds-*` classes |
| `components/` | `layout` (Stack, Cluster, Grid, Container, Divider), `type` (Text, Heading), `actions` (Link, Button, IconButton, Chip, Breadcrumbs), `data` (Stat, StatGrid, KeyValue, ListRow, Table, Badge, Legend, EmptyState, Skeleton, Icon, MapFrame), `forms` (Field, Input, Textarea), `shell` (AppShell, PageHeader, Section, Page) |

The living style guide is at `/design-system`, and the candidate directions are
at `/design-system/compare`. Both are visible to admins, and to everyone on a
local dev server.

## rules

- **Spacing comes from the scale.** Use `gap` props (`"1"` … `"16"` = 4 … 64 px)
  and component padding. No inline pixel values.
- **Color comes from tokens.** No literals. Color is only for meaning: the
  route, a pr, heart-rate zones, focus, a destructive action.
- **Links are text, buttons are buttons, chips select.** Navigation never uses a chip.
- **Icons go through `<Icon>`.** It masks the SVG and fills it with
  `currentColor`, so icons are correct in both themes without `invert()`.
- **Components take copy as props.** They never contain site copy.
- **Why plain classes, not Tailwind padding:** v1's unlayered
  `* { margin: 0; padding: 0 }` reset beats Tailwind's layered utilities. The
  `.ds-*` classes are unlayered too and win on specificity, so the system works
  inside today's site without touching v1.
